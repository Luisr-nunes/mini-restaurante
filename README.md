## 📋 Sobre este Repositório

O projeto **Mini Restaurante** é uma aplicação web interativa que funciona como um cardápio digital e sistema de pedidos. Ele engloba a exibição estruturada de produtos, gerenciamento de estado (itens adicionados ao carrinho) e o cálculo em tempo real dos valores, simulando um ambiente real de PDV (Ponto de Venda) ou Delivery.

---

## 📁 Principais Funcionalidades

| Feature | Status | Descrição |
|---|---|---|
| `Cardápio Digital` | ✅ | Renderização dinâmica de pratos, preços e descrições |
| `Carrinho de Compras` | ✅ | Lógica de adicionar, remover e alterar quantidades |
| `Cálculo de Totais` | ✅ | Atualização matemática do valor final do pedido do usuário |
| `Responsividade` | ✅ | Interface adaptável para dispositivos móveis e desktop |

---

## 🎯 Objetivo do Projeto

Integrar as camadas de Front-End (Interface e UX) com lógicas de negócio (Back-End/Estado da aplicação), criando um produto de software completo, funcional e próximo à realidade do mercado de e-commerce.

---

## 📌 Como Executar Localmente

1. Clone este repositório para o seu computador.
2. [Abra o arquivo `index.html` em seu navegador OU, se for um projeto node/react, rode `npm install` seguido de `npm start`].
3. Interaja com a interface para testar a adição de itens ao pedido e observar as mudanças de estado da aplicação.
