[Ler em Português](README.md)

A static three-page website for Yamey, a fictional Korean restaurant, built with plain HTML and CSS.

## Pages

| File | Content |
| --- | --- |
| `index.html` | Restaurant introduction |
| `cardapio.html` | Menu in tables, with dishes such as bulgogi, japchae and kimchi and their prices |
| `contato.html` | Contact information |

All pages share the header, navigation menu and footer. The content is in Portuguese.

## Concepts practiced

- Semantic structure with `header`, `nav` and `footer`
- Navigation between pages with internal links
- Tables for the menu
- Styling with a single stylesheet: typography, colors, spacing and layout
- File organization in `css/` and `img/`

## Structure

```
mini-restaurante/
├── index.html
├── cardapio.html
├── contato.html
├── css/styles.css
└── img/            # logo, background and dish photos
```

## Viewing

No dependencies: clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/Luisr-nunes/mini-restaurante.git
```
